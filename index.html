Import Programs

Upload the Budget Assumptions spreadsheet (.xlsx or .csv), or paste rows below. We map the columns, build a starter cost part from the Cost Basis, and keep the original cost text as the summary — you refine specifics in the editor.

  • Department — groups the program (Accounting, Marketing, Technology…).
  • Cost Name — the program name. Required.
  • Program Owner — name/email shown under the title on the card.
  • Elective/Non-elective — type "Non-elective" for required programs; anything else is treated as elective.
  • 2027 Cost — the cost as written. The first $ amount becomes the starter rate; the full text is kept as the card's cost summary.
  • Cost Basis — builds the starter cost part: Flat Fee, Per Unit, Per [thing] (Per Elevator, Per Associate, Per Aff Unit…), or % of income / % of CapEx. Tiered or multi-rate costs import as manual for you to build in the editor.
  • Setup Fee — description of any one-time setup fee.
  • Billing Frequency — Monthly · Quarterly · Bi-annual · Annual · As incurred · One-time.
  • Billing Start — the month it bills (e.g. January), or "When Implemented" to follow the property's transition.
  • Min / Max — optional per-period floor/ceiling on the cost (e.g. $250 min, $500 max).
  • Yardi GL / Onesite GL / Pace GL — GL codes for each system.
  • Prior Year Cost — a note about last year's cost / any change (e.g. "Up from $1.50/unit", "No change"). Shown in the card's Details panel.
  • Details — description shown in the card's Details panel.
